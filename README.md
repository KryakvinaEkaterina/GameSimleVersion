# Escape from Laboratory

Консольная текстовая игра на языке C. Игрок исследует лабораторию, собирает ключи, избегает опасностей и пытается выбраться к выходу.

## Что реализовано

- Управление: WASD для движения, Q для выхода.
- Параметры персонажа: здоровье, энергия, ключи, счётчик комнат.
- Случайные события и находки при входе в комнату.
- Проверка столкновений со стенами.
- Поддержка русского языка.
